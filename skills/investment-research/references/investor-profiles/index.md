# Investor profile catalog

These profiles are dated research starting points. Check their evidence and current facts before using them. The historical records describe the stated vehicles, not guaranteed or individually attributable results.

- [Warren Buffett](warren-buffett.md): business quality, durable economics, and purchase price.
- [Peter Lynch](peter-lynch.md): familiar businesses as research leads, followed by company analysis.
- [John Bogle](john-bogle.md): broad index exposure and investment costs.

To research a different person, use [the profile method](../investor-profile-method.md) and [template](template.md). Add a catalog entry only when the user asks to save the profile in this package. For profiles in a separate private repository, use [the private source guidance](../private-profile-sources.md).
