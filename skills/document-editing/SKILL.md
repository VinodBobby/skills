# Purpose

Make the requested document changes with a clear audit trail of what changed and what still needs review.

# Workflow

1. Identify the audience, purpose, requested changes, and file format. Read the full source and preserve the author's intent, terminology, and structure unless asked to revise them.
2. Apply focused edits. Keep claims and numbers traceable to supplied evidence. Preserve styles, headings, tables, links, and fields where the format supports them.
3. Use tracked changes or comments only when requested. Do not accept or reject existing reviewer changes without authorization.
4. Check the saved document for missing sections, broken links, inconsistent terminology, and formatting changes. For paginated formats, render representative pages and inspect layout when tools allow.
5. Deliver the edited file and summarize substantive changes. State any formatting or verification limits.

# Requirements

Use the document tools or libraries available in the current environment. If they cannot preserve or render the requested format, do not silently substitute a plain-text file; explain the limitation and offer a compatible path.
