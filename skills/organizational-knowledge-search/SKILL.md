# Organizational Knowledge Search

Answer internal questions from the organization's sources of record. Use available search or connector tools; do not assume a particular vendor or that every source is connected.

## Search and verify

1. Extract the system, process, term, or decision the user wants to understand. Add names, dates, or team context that make the search more precise.
2. Search the most likely connected sources. Search across sources when the system of record is unclear; use targeted queries when the user names a source or broad search returns noise.
3. Open the most relevant authoritative and recent results. Fetch full content when snippets do not establish the claim. Do not read every result when a few sources answer the question.
4. Compare sources for status, date, and scope. Treat an implementation record or recent incident as evidence that documentation may be stale; state the discrepancy instead of silently choosing one.
5. Answer by topic. Cite each material claim with a source title and link, and distinguish documented facts, current observations, and inference.

When the connected sources do not answer the question, state what you searched and where the evidence stops. Ask for access or another source only when it is needed to continue. Do not claim to have searched systems that were unavailable. Do not create or edit internal records unless the user requests that action.
